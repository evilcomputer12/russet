# Create a virtual iPhone

Russet creates an iPhone that runs inside this PC: by default an iPhone17,3
with iOS 27.0.1, the pairing verified end to end on Linux. You can choose
another device and iOS version on the setup page.

The virtual iPhone opens in an editor tab with a device frame. Click or drag on
its screen to touch, type while it has focus, and use **Home**, **Lock**,
**Volume**, **Rotate** and **Screenshot** from the tab's toolbar or with
Ctrl+Shift+H, Ctrl+Shift+L, Ctrl+Shift+Up/Down, Ctrl+Shift+Left/Right and
Ctrl+Shift+S.

It appears next to your USB iPhones in the run destination picker.
