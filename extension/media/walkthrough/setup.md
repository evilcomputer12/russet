# Set up this PC

**Open Setup** shows every step Russet needs on Windows, in order, with its
status, progress and log:

- **Windows Subsystem for Linux** and the private Russet backend, which you never
  have to log into;
- **Apple Devices** from the Microsoft Store, which lets Windows talk to an iPhone
  over USB;
- **xtool** and the **iOS SDK**, read from the Xcode archive you download from
  Apple;
- the **virtual iPhone** engine and the virtual iPhone itself.

Each step can be retried or repaired, and long steps can be cancelled and
resumed later.
