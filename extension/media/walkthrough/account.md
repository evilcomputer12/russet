# Sign in

- **Apple ID**: sign in with your Apple ID and password, then the code Apple shows
  on your trusted device (or sends by text message). Free accounts run apps on
  your own devices for 7 days at a time; a paid Apple Developer Program membership
  signs for a year. Russet never stores your password in the IDE or in settings.
- **App Store Connect API key**: for paid teams, add the `.p8` key you created in
  App Store Connect.
